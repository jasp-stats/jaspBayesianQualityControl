# The Bayesian Quality Control Module

## Overview

<img src='inst/icons/qualityControl-module.svg' width='149' height='173' align='right'/>

**JASP Bayesian Quality Control module** is an add-on module for JASP that provides Bayesian tools for assessing whether a manufacturing process meets specified quality criteria.

## R Packages

<img src='https://www.r-project.org/logo/Rlogo.svg' width='100' height='78' align='right'/>

The Bayesian quality control functionality is served by the following R packages:

- **qc** - Bayesian process capability estimation, sequential updating, and visualizations ([qc on GitHub](https://github.com/FBartos/qc))

## Analyses

The organization of the analyses within the Bayesian Quality Control module in JASP is as follows:

```text
-- Capability Analysis
   - Process Capability Study
```
